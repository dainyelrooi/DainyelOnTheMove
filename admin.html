    What can I change here?

    Existing pages: headings, paragraphs, link labels and destinations, photographs, photo descriptions and crops. Each field starts with the real website content. Use Restore original beside a field to undo that edit. Shared header announcements and footer changes appear across public pages. In Shared header & footer, edit the two short announcements and their links; clear both fields to hide an announcement. Page summaries and card text can be edited separately where they appear.

    New stories, Field Notes and facts: use Create & publish. That editor adds chapters, reading time, a cover, a banner and photo galleries automatically.

    Short formatting: **bold**, *italic* and [label](https://example.com). An empty line or a line break stays visible. HTML is displayed as text.

    Kept separate: questions, contact messages, Postcards, the content calendar and your shared location have their own workspace tabs. Publishing website changes sends no email.

    Not an editor for everything: page structure, navigation menu items, existing video files, cookie/privacy rules, sign-in settings and the secret journey feed remain protected. These changes need a technical release. New video links can be included in your stories.

    Edited content loads when the website connects to storage. Without JavaScript or that connection, the original static content is the fallback. Search-engine/social previews may still use the original static text.
